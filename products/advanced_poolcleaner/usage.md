# Advanced Poolcleaner — Usage

Open office /pooljob or F7. Invite before starting (four max, 12 m). Short/medium/long use 1/2/3 pools and 3/4/6 tasks per pool. Members reserve separate tasks at current pool. Skill/progress actions include vacuum, skim, sweep, backwash, chemicals, filter. Complete pool to advance.

Final task automatically pays; office return is not required. Defaults: 2,600–3,400 / 5,200–6,800 / 8,500–11,000 and 90/190/330 XP. Each mode pays base to each member; split divides base first. +5% per extra member; Chemistry x1.05 then Master x1.08; Route x1.10 XP. Spend progression skill points.

Inventory requirements are off by default. Enabled chemicals/filter requirements check and optionally consume configured items. Pool definitions need enough task types for chosen difficulty.

Values are supplied defaults; administrators may customize them. Source: current config and registered gameplay handlers.
