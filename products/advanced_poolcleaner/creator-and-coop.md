# Poolcleaner — Creator and cooperative routes

With poolcleaner.admin, run /poolcreator at the pool. Name it, capture the anchor and walk to each task point. E records, X skips a task, Backspace cancels. Give each point an accessible position/heading in the real pool/MLO. Save to advanced_pool_locations.

Default config pools and saved DB pools coexist; DB definitions are persistent. Existing delete flow targets DB-created pools. A route considers only pools with enough available task types; long requires six. Incomplete points can therefore be valid creator records but unsuitable for a long job.

Co-op members share current pool/progress. Tasks have server locks with source/name and release behavior. Completion rechecks task state, active pool, proximity, elapsed time and item consumption. Members can work different tasks at the same pool. The pool advances when remaining tasks are done and final completion pays without an office-return step.

Profile rows store levels/XP/reputation/completed jobs/earned money/task counts/skill points/skill JSON. Active groups/missions remain memory state. Test completion, cancel/disconnect and creator save/restart on staging.
