# Advanced Orbital

Authorized-terminal orbital surveillance and paid strikes with manual/automatic targeting, vision modes, safe zones, daily limits, SQL logs and native GTA orbital effects. Impact handling involves the server and relevant clients.

| Release | Resource | Config |
| --- | --- | --- |
| **1.3.0** | `advanced_orbital` | `shared/config.lua` |

{% hint style="info" %}
Active job/grade/duty, ACE or public terminal access is checked server-side. Standalone without a custom economy requires DefaultPrice and every terminal's price to be zero. oxmysql and the supplied SQL are still required.
{% endhint %}
