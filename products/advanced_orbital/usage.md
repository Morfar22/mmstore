# Advanced Orbital — Usage

Approach an authorized terminal. Choose surveillance (no firing), manual reticle/lock or automatic nearest valid streamed vehicle targeting. WASD moves, Shift speeds up, wheel zooms, V switches vision, Q locks, Space requests strike and Backspace exits.

Server checks session/access/payment/limits/cooldown/target/safe zones. Moving targets can be re-resolved at impact. Defaults: 250,000 bank price, 3 s countdown, 180 s cooldown, 3 strikes/player/day and 15/server/day. SQL dates use server calendar. Native explosion tag is hard-locked 59. Player/vehicle consequences include owning/relevant-client application; live network edge cases still need testing.

Values are supplied defaults; administrators may customize them. Source: current config and registered gameplay handlers.
