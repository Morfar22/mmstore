# Advanced Vet DLC — Usage

1. Use the configured clinic workstations or /vet (F10) with Vet access.
2. Select a nearby supported animal/player patient; world animals must have the supported network identity.
3. Read history/triage and request consent for configured invasive care.
4. Place at a saved table, then treat, X-ray or run phased surgery (prepare, anesthesia, operation, closure, recovery).
5. Manage chip/vaccination records and physical kennel admissions/discharge.
6. Pharmacy prescriptions issue TWO items: product and metadata-rich vet_prescription document.
7. Manage invoices/appointments; customers use /vetpay.

Player dogs can /vetgetup for emergency release. Triage/vaccination values are RP gameplay. Optional Vet training opens a temporary channel for an active Service K9, without pairing the veterinarian or granting police authority. Initial selection is proximity-based; active training commands do not reapply the old distance gate.

Values are supplied defaults; administrators may customize them. Source: current config and registered gameplay handlers.
