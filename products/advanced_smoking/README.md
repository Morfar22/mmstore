# Advanced Smoking

Smoking, accessories, offers/loans, placeable props, containers, collectibles and a persistent shop. Supplied in-game branding is Nordlys and can be customized separately from MM - Store.

| Property  | Value                   |
| --------- | ----------------------- |
| Folder    | `advanced_smoking`      |
| Version   | cerulean                |
| Framework | QBox + TGIANN Inventory |
| Config    | `config.lua`            |
