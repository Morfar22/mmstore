# Yacht — Access, storage and paid upgrades

Explicit owner/crew/guest entries live separately from selected service access modes. everyone allows public service features through modeAllows, no_one is owner-only, crew maps to crew, friends maps to guest, and organization/motorcycle_club map to crew. Social Club data is not queried.

Storage open uses explicit access and configured distance. Fleet access has its own mode. Package geometry gives Orion one tender/one jetski/one helicopter slot, Pisces two/two/one and Aquarius two/four/one; catalog allows only designated packages for each product.

Server validation is separate from local cinematic/prop previews. Default resale is 50%; verify funds/state once after buy/sell/restart on staging.
