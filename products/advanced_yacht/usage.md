# Advanced Yacht — Usage

Buy/name/place at broker, manage /yachtmenu or F7. Board/leave use scripted cameras; X skips. Orion 6,000,000 (70 stash slots/300,000 weight); Pisces 7,000,000 (90/450,000); Aquarius 8,000,000 (120/650,000). Jacuzzi is Pisces/Aquarius. All supplied packages have defense/helipad. Currency DKK.

Owner controls rename/relocation/customization/guests/crew/service options. Rename/relocation/flag defaults 25,000, relocation cooldown 60 s, one yacht/character. Vehicle addons cost separately, limited by catalog AND physical package slots; default resale 50%.

Friends/organizations/associates are mapped to explicit yacht guest/crew records, not Social Club. Explicit storage permission and public service modes are different checks.

Values are supplied defaults; administrators may customize them. Source: current config and registered gameplay handlers.
