# Advanced Pausemenu

A QBox pause menu with character/money information, service counts, player list, inventory weight where supported, FAQ, updates, shortcuts and waypoints. Native map/settings bridges return to the custom menu.

| Property | Value |
| --- | --- |
| Folder | `advanced_pausemenu` |
| Version | cerulean |
| Framework | QBox |
| Config | `config.lua` |
