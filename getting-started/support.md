# Support checklist

Include product/manifest version, framework/inventory/provider versions, exact reproduction, expected/actual result, relevant console and F8 text, whether one/all players are affected, sanitized config and startup order. For positioning include vehicle model/map/station. Use private tickets for player-specific data; remove tokens, webhooks, passwords, license IDs and phone numbers. Enable debug/developer tools temporarily and disable afterwards. No F8 error does not prove a server action succeeded.
