# Apply the MM – Store visual style

The content uses a restrained dark navy, violet and white identity: short introductions, product facts, ordered setup, compatibility tables and clear hints. The home cover is bundled as .gitbook/assets/mm-store-cover.png.

In GitBook's site overview → Customization apply:

| Setting | Value |
| --- | --- |
| Site title | MM – Store Docs |
| Primary accent | #925CFF |
| Dark background reference | #10121C |
| Main font | Inter, or the available clean sans-serif |
| Code font | JetBrains Mono, or the available monospace |
| Default mode | Dark, with reader light/dark toggle |
| Corners | Subtle rounded corners |
| Navigation | Product hierarchy from SUMMARY.md |
| Site logo | Your existing MM – Store logo |

Upload your existing shop logo in the site UI. The included cover is a documentation wordmark treatment, not a replacement for the shop logo. Theme/custom-font availability may depend on your account. Use the bundled preview to review content locally; published GitBook styling is controlled by your account settings.
