F7 collisions are real when installing several products. Rebind in FiveM key settings and change defaults for new clients. Existing user mappings can survive config changes. Also resolve K9/Smoking G/H and Diving G. Suggested allocation: K9 F7, Radio F8, Pool F6, Yacht F9, Vet F10, only if free on your server; scripts were not modified to apply this.
