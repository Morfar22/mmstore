# MM Bridge

One integration layer for the Advanced series. Select a provider centrally; each product still defines its gameplay and its resource-specific extensions.

Use **mm_bridge 0.3.0+** with the documented product releases. Start providers first, the bridge second, and consumers last. See [product compatibility](compatibility.md), [configuration](configuration.md), [API](api.md) and [custom adapters](custom-adapters.md).

A compatible framework does not make every inventory, phone or society bank compatible. Read the per-product limits before selecting providers.
